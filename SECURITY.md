# Security policy

If you find a security issue in the DataMatrix generator library (`dmgen`) — the library, the C ABI, the Python package,
the `dmgen` command-line tool or the license check — please report it privately by email to
[libscanner@yandex.com](mailto:libscanner@yandex.com) rather than opening a public issue.

Please include the product version (`dmgen --help` prints it on the first line), the platform, and the
steps or input needed to reproduce the problem. We will acknowledge the report and keep you informed about
the fix.

Supported version: 1.0.x.
